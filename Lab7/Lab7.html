Lab 7

Vertical Model Tiering Evaluation

Evaluating GPT-5.6 Luna, Terra, and Sol Agents on Latency, Cost, Token Efficiency & Code Quality

Goal

Evaluate three distinct model capability tiers across simple and complex software engineering tasks:

Fast & Cheap
LUNA (luna-agent)

gpt-5.6-luna — Optimized for maximum speed and minimal token cost. Ideal for simple scripts and straightforward formatting tasks.

Balanced
TERRA (terra-agent)

gpt-5.6-terra — Balanced production model tier providing an optimal trade-off between intelligence, speed, and cost.

High Reasoning
SOL (sol-agent)

gpt-5.6-sol — High reasoning and agentic model tier designed for complex software architectures, transaction sagas, and edge cases.

Execution & Analysis Pipeline

For each task level, run luna-agent → terra-agent → sol-agent sequentially, capture telemetry JSONL logs, and execute the run-analyzer agent to extract deterministic metrics via measure_metrics.py and perform static code quality analysis.

Model Agent Team Roster

The 4 specialized agent definitions configured in .opencode/agent/:

Agent Name File Location Model Tier Primary Role
luna-agent .opencode/agent/luna-agent.md gpt-5.6-luna Fast, cost-efficient benchmark agent for basic tasks.
terra-agent .opencode/agent/terra-agent.md gpt-5.6-terra Balanced benchmark agent for standard production feature implementations.
sol-agent .opencode/agent/sol-agent.md gpt-5.6-sol High reasoning benchmark agent for complex architectural tasks & edge cases.
run-analyzer .opencode/agent/run-analyzer.md gpt-5.6-sol Executes measure_metrics.py against JSONL runs & compares Luna, Terra, Sol code quality.

Scenario 1 — Vertical Benchmark on Simple Task

Execute Luna, Terra, and Sol model tiers sequentially against task/simple_task.md, followed by metrics and quality analysis via run-analyzer:

Step 0: Workspace Cleanup
cd lab7;rm -rf runs/* .pytest_cache
Step 1: Execute LUNA Agent (Simple Task)
opencode run --agent luna-agent --format json \
"Engineering Task: task/simple_task.md
Output: runs/simple_luna_solution.py" \
| python -u live_view.py runs/simple_luna.jsonl
Step 2: Execute TERRA Agent (Simple Task)
