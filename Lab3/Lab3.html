Goal

Answer the core system design question: How do I automatically use benchmark evidence to choose an appropriate model for an engineering task?

DETERMINISTIC VERIFICATION & ESCALATION
Core Principles
  • Don't route based on model reputation. Route based on evidence.
  • Choose the least expensive model that reliably meets the quality bar for the task.
  • Cost per model call is NOT the same as cost per completed engineering task.

Target Architecture

Simple, decoupled architecture enforcing strict separation of concerns:

Classifier Agent
TaskClassifier LLM Agent
Invokes claude-3-5-haiku agent to answer: What kind of task is this? (Does NOT select execution model)
Policy
RoutingPolicy
Answers: Which model should handle it based on evidence?
Runner
OpenCode Subprocess
Executes selected agent via OpenCode + AWS Bedrock
Verifier
pytest Deterministic
Answers: Did the code pass tests? (Never uses an LLM)
