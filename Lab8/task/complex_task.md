# Order Cancellation

Implement order cancellation in `solution.py`.

Customers should be able to cancel an order before it has progressed
too far.

When an order is cancelled, reserved inventory should become
available again.

Paid orders may require a refund.

Cancellation requests may occasionally be submitted more than once.

The service may receive simultaneous cancellation requests.

Return a useful result describing what happened.

Use Python standard library only.
