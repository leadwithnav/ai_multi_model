# Lab 8: Context Handoff — Cold vs. Context-Aware Retry Experiment

## Goal
Build a practical experiment that answers:
> **"When the first AI coding attempt fails, does retrying with structured failure context perform differently from retrying cold with only the original engineering request?"**

This is an empirical experiment comparing two retry strategies on AI coding tasks after an initial failure.

---

## Controlled vs Variable Conditions

### Controlled Variables (Held Constant Across All Runs)
- **Model**: `GPT-5.6 Terra` (`amazon-bedrock/us.openai.gpt-5.6-terra`)
- **Coding Agent**: `terra.md`
- **Diagnostician Agent**: `diagnostician.md` (Sonnet)
- **Task**: Inventory Concurrency Incident INC-9204 (`task/request_01.md`)
- **Target Repository**: `order_flow_service`
- **Evaluation Suite**: `hidden_eval/test_request_01.py`
- **Sample Size**: 3 trials per branch

### Experimental Variable
- **Supplied Context**:
  - **Branch A (Cold Retry)**: Original engineering request ONLY.
  - **Branch B (Context-Aware Retry)**: Original engineering request + Structured Failure Handoff Brief (`artifacts/handoff_brief.json`).

## Experiment Pipeline

```
                     ┌────────────────────────────────┐
                     │       Initial Attempt 1        │
                     │       (GPT-5.6 Terra)          │
                     └───────────────┬────────────────┘
                                     │
                                     ▼
                     ┌────────────────────────────────┐
                     │   Acceptance Test: FAILED      │
                     │    (TOCTOU Race Condition)     │
                     └───────────────┬────────────────┘
                                     │
                                     ▼
                     ┌────────────────────────────────┐
                     │      Diagnostician Agent       │
                     │ (Synthesizes Handoff Brief)    │
                     └───────────────┬────────────────┘
                                     │
                 ┌───────────────────┴───────────────────┐
                 │                                       │
                 ▼                                       ▼
    ┌─────────────────────────┐             ┌─────────────────────────┐
    │   BRANCH A: COLD RETRY  │             │ BRANCH B: HANDOFF RETRY │
    │    (3 Trials x Terra)   │             │   (3 Trials x Terra)    │
    │  Original Request Only  │             │   Request + Handoff     │
    └────────────┬────────────┘             └────────────┬────────────┘
                 │                                       │
                 └───────────────────┬───────────────────┘
                                     │
                                     ▼
                     ┌────────────────────────────────┐
                     │   Metrics & Comparison Report  │
                     │ (Pass Rate, Latency, Tokens)   │
                     └────────────────────────────────┘
```
