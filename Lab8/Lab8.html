Lab 8

Direct Build vs. Design-First Strategy

Evaluating Architectural Rigor, Code Quality, Token Costs & Latency Trade-offs across Simple and Complex Tasks

Goal

Compare two fundamentally different software engineering execution strategies for autonomous AI agent workflows across simple and complex engineering tasks:

Strategy 1
DIRECT (Direct Implementation)

The coordinator delegates directly to direct-builder, which writes solution.py in a single pass without prior architectural blueprinting.

Strategy 2
DESIGN_FIRST (Spec-Driven Architecture)

The coordinator delegates to designer first to generate an architectural blueprint (design.md), then invokes design-builder to synthesize solution.py.

Evaluation Pipeline

After running both strategies against a task requirement, the code-quality-analyzer agent independently compares design_first_solution.py and direct_solution.py to produce an objective engineering evaluation report in runs/quality_comparison.md.

Subagent Team Roster

The 5 specialized agent definitions configured in .opencode/agents/:

Agent Name File Location Role & Responsibility
coordinator .opencode/agents/coordinator.md Orchestrates strategy delegation based on prompt input (DIRECT vs DESIGN_FIRST).
direct-builder .opencode/agents/direct-builder.md Synthesizes implementation code directly in a single pass without an upfront design phase.
designer .opencode/agents/designer.md Analyzes requirements and creates a comprehensive architectural specification (design.md).
design-builder .opencode/agents/design-builder.md Synthesizes clean implementation code guided strictly by the architectural specification in design.md.
code-quality-analyzer .opencode/agents/code-quality-analyzer.md Independently inspects and evaluates both implementations to generate runs/quality_comparison.md.

Strategy Comparison & Architecture Flow

Understanding the architectural trade-offs between one-step execution and multi-stage spec-driven building:

Metric / Dimension DIRECT Strategy DESIGN_FIRST Strategy
Execution Flow Coordinator → direct-builder → solution.py Coordinator → designer (design.md) → design-builder → solution.py
Latency & Speed Lowest Latency (Single turn execution) Higher Latency (Two sequential LLM reasoning turns)
Token Cost Lowest Token Usage Higher Token Usage (Blueprint + Implementation context)
Code Quality & Structure Monolithic or rapid synthesis; potential edge-case misses on complex tasks. Modular, well-structured, superior separation of concerns & robust error handling.
Best Suited For Simple scripts, quick prototypes, well-bounded bug fixes. Complex distributed sagas, multi-component microservices, mission-critical systems.
