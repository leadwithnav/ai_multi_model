Lab 8 — Context Handoff Experiment

Cold Retry vs. Context-Aware Failure Handoff Retry

Empirical Question

When an initial AI coding attempt fails, how does retrying cold (with only the original engineering request) compare to retrying with a structured failure handoff brief (root cause diagnosis, failed assumptions, suggested remedy)?

Controlled Variables: Model (GPT-5.6 Terra), Coding Agent (`terra.md`), Target Repo (`order_flow_service`), Task (`request_01.md`), and Hidden Test Suite are held strictly constant across 3 trials per branch.

Experiment Pipeline Flow

┌──────────────────────────────────────────────┐ │ Attempt 1 Execution │ │ Model: GPT-5.6 Terra │ └──────────────────────┬───────────────────────┘ │ ▼ ┌──────────────────────────────────────────────┐ │ Acceptance Test: FAILED │ │ (INC-9204 TOCTOU Race Condition) │ └──────────────────────┬───────────────────────┘ │ ▼ ┌──────────────────────────────────────────────┐ │ Diagnostician Agent │ │ Synthesizes artifacts/handoff_brief.json │ └──────────────────────┬───────────────────────┘ │ ┌───────────────────────────────┴───────────────────────────────┐ │ │ ▼ ▼ ┌───────────────────────────┐ ┌───────────────────────────┐ │ BRANCH A: COLD RETRY │ │ BRANCH B: HANDOFF RETRY │ │ (3 Trials x GPT-5.6) │ │ (3 Trials x GPT-5.6) │ │ Original Request Only │ │ Request + Handoff Brief │ └────────────┬──────────────┘ └────────────┬──────────────┘ │ │ └───────────────────────────────┬───────────────────────────┘ │ ▼ ┌──────────────────────────────────────────────┐ │ Metrics & Side-by-Side Analysis Report │ │ (Pass Rate %, Latency, Token Cost) │ └──────────────────────────────────────────────┘
