EVIDENCE-BASED WORKLOAD ROUTING

Execution Loop For Each Model & Task

Standard 4-Step Loop
Step 1
Run Model

Run opencode with --format json. Parse metrics with metrics_helper.py.

Step 2
Evaluate

Run task's instructor evaluation test suite.

Step 3
Record

Record Pass Rate, Latency, Cost, and LLM Steps.

Step 4
Reset

Run .\reset.ps1 or ./reset.sh before next run.

Workload 1 — Feature Implementation

Requirement: Implement order cancellation and inventory stock restoration (`cancel_order` & `POST /orders/{id}/cancel`).

Go to Lab2
cd Lab2
Run Implementation Task using claude-3-5-sonnet
opencode run --agent claude-3-5-sonnet --format json "$(cat benchmark/implementation/TASK.md)" > run1.jsonl;
Check and Record Metrics
python metrics_helper.py claude-3-5-sonnet run1.jsonl
Instructor Evaluation — Task 1
pytest instructor_tests/test_implementation_acceptance.py -v
