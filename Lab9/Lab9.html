Lab 9

Workflow Orchestration Strategies

Evaluating ALL_LOW vs ALL_HIGH vs TIERED Team Strategies on Simple & Complex Tasks

Goal

Evaluate three workflow orchestration strategies (ALL_LOW, ALL_HIGH, TIERED) across two distinct complexity levels: task/simple_task.md and task/complex_task.md.

Multi-Agent Orchestration Flow

The coordinator agent reads the selected strategy prompt, orchestrates the 3-stage lifecycle (Architecture design.md → Implementation solution.py → Verification test_solution.py), collects run telemetry into runs/, and invokes the runs-analyzer agent to produce comparison.md.

Strategy Allocation Matrix

Each strategy configures different model capability tiers for the Architect, Builder, and QA roles:

Strategy A
ALL_LOW

Low-cost / fast agents across all roles to minimize cost and latency.

Architect: low-architect
Builder: low-builder
QA: low-qa
Strategy B
ALL_HIGH

Maximum reasoning capability across all roles for peak quality.

Architect: high-architect
Builder: high-builder
QA: high-qa
Strategy C
TIERED (Optimal)

High reasoning for architecture, balanced builder, and fast QA.

Architect: high-architect
Builder: mid-builder
QA: low-qa

Multi-Agent Team Roster

Exact 11 specialized agent definitions in .opencode/agent/ orchestrating the workflow:

Agent Role Agent File Model Binding Primary Responsibility
Coordinator coordinator.md gpt-5-6-luna Orchestrates strategy delegation, manages workflow steps & retry loops.
High Architect high-architect.md gpt-5-6-sol High-reasoning analysis of requirements; generates architectural design.md.
High Builder high-builder.md gpt-5-6-sol High-reasoning code synthesis; implements design into solution.py.
High QA high-qa.md gpt-5-6-sol High-reasoning verification; generates test_solution.py and runs pytest.
Mid Architect mid-architect.md gpt-5-6-terra Balanced architecture analysis & system design.
Mid Builder mid-builder.md gpt-5-6-terra Balanced code synthesis for production feature implementations.
Mid QA mid-qa.md gpt-5-6-terra Balanced unit test verification & regression checks.
Low Architect low-architect.md gpt-5-6-luna Fast, cost-optimized architectural design for basic requirements.
Low Builder low-builder.md gpt-5-6-luna Fast, cost-optimized code generation for simple logic.
Low QA low-qa.md gpt-5-6-luna Fast, cost-optimized test suite execution & verification.
Runs Analyzer runs-analyzer.md gpt-5-6-terra Analyzes JSONL runs & JSON metrics across all strategies; creates comparison.md.
